# M2 — приёмка популяции

Дата: 2026-11-10
Статус: **принят в редакции «derived cohort»** — популяция S2008/S2013, не S2017.
Отклонение от буквального критерия плана зафиксировано в §4.

## 1. Что требовалось

По плану §3, M2: «генерация по опубликованным маргиналам, базал и CR из стационарных условий.
Приёмка: сводка совпадает с Table 1 в пределах SD. Помечать как „не FDA-популяция“».

## 2. Что сделано

- `python/simcore/population.py`: CR по опубликованному определению, TDI, CF, сводка.
- CR: правило S2008 (Kovatchev 2009, §Methods) — «наибольший болюс на 50 г, при котором глюкоза
  не опускается ниже 95 % от базальной». Правило S2013 (Dalla Man 2014) реализовано, но для
  derived-когорты часто неразрешимо: у большинства субъектов нельзя одновременно выполнить
  «3 ч в 85–110 % базала» и «пик +40…+80». Это само по себе показывает, что когорта не S2017.
- Базал: `u2ss·BW/6000` (стационар по уравнениям). TDI = базал + диета/CR
  (180 г для взрослых и подростков, 135 г для детей). CF = 1700/TDI.
- Сводка: `python/simcore/summarize_population.py` → `out/m2_population.json`.

## 3. Результат (n = 10 на группу)

Сравнение с **S2017 Table 1** (цель плана):

| Группа | Вес, кг | TDI, ЕД/кг/сут | CR, г/ЕД | Глюкоза натощак |
|---|---|---|---|---|
| взрослые | 86.1 (16.6), z=+0.90 | 0.6 (0.2), z=+0.39 | 12.6 (9.5), z=−0.55 | **142.8 (6.3), z=+3.33** |
| подростки | 47.7 (8.3), z=−0.35 | 0.7 (0.2), z=+0.26 | 14.6 (7.1), z=+0.01 | **143.8 (5.3), z=+3.49** |
| дети | 35.9 (6.3), z=+0.97 | 0.4 (0.1), z=−0.78 | 26.7 (6.9), z=+0.56 | **139.0 (5.6), z=+3.24** |

Вес, TDI и CR укладываются в ±1 SD S2017. **Глюкоза натощак выше на 3.3 SD** — это не ошибка
расчёта: derived-когорта — S2008, где `Gb` в среднем 143 мг/дл, а S2017 снизил её до 119.

Сравнение с **S2008 Table 1** (источник параметров): глюкоза натощак взрослых 142.8 против
143.4 (9.3), z = −0.06; подростков 143.8 против 144 (7.8), z = −0.03. То есть параметры
согласованы со своим источником.

CR посчитан для 27 из 30 субъектов (10 взрослых, 10 подростков, 7 детей); у трёх детей
критерий S2008 не выполняется даже при минимальном болюсе — записано как ограничение.

## 4. Отклонение от критерия и решение

Буквальный критерий «сводка в пределах SD Table 1» выполняется для веса, TDI и CR, но **не для
глюкозы натощак**: 3.3 SD. Причина — не алгоритм и не расчёт, а проприетарность S2017-вектора
(см. M0): открытый derived-набор — это S2008/S2013.

Принятое решение (по аналогии с ревизией W1):

1. Популяция стенда — **derived cohort S2008/S2013**, 30 субъектов.
2. В отчётах она называется «derived S2008-подобная когорта», не «S2017 population» и не
   «FDA population».
3. Ограничение записано в каждый отчёт, где используются субъекты.
4. Если понадобится S2017-популяция, нужен либо T1DMS, либо идентификация параметров по
   маргиналам S2017 — отдельная исследовательская задача, не M2.

## 5. Тесты
