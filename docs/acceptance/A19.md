# A19 — DynISF на CF из модели, 120 субъектов

Дата: 2026-11-12
Статус: **принят**. Результат A16 подтверждён на расширенной когорте: на агрессивном профиле
DynISF доминирует.

## 1. Постановка

- 120 субъектов (30 базовых + 3 копии), FCL 24 ч, профиль по CF из модели (A3, в 2.4 раза ниже
  правила), без вариативности.
- Плечи `off`, `autoisf`, `dynisf`, одинаковый сид CGM; парная статистика.
- 360 прогонов, 433 с.

## 2. Средние

| Плечо | TIR | TBR<70 | LBGI | SMB | Доза | В падении |
|---|---|---|---|---|---|---|
| off | 0.634 | 20.9 % | 6.03 | 79 | 38.1 | 0.276 |
| autoisf | 0.617 | 22.6 % | 6.36 | 72 | 39.3 | 0.346 |
| dynisf | **0.695** | **10.0 %** | **3.09** | 80 | 33.3 | 0.283 |

## 3. Парные разности (n=120)

| Сравнение | ΔTIR | ΔTBR | ΔLBGI | Δдоза | Δпадение |
|---|---|---|---|---|---|
| off → autoisf | −1.7 п.п. (p<0.0001) | +1.7 (p<0.0001) | +0.33 | +1.20 | +7.0 п.п. |
| off → dynisf | **+6.1 п.п. (p<0.0001)** | **−10.9 (p<0.0001)** | **−2.95 (p<0.0001)** | −4.86 | +0.7 (ns) |
| autoisf → dynisf | **+7.7 п.п. (p<0.0001)** | **−12.6 (p<0.0001)** | **−3.27 (p<0.0001)** | −6.06 | **−6.3 п.п.** |

## 4. Сравнение с A16 (30 субъектов)

| Метрика | A16, n=30 | A19, n=120 |
|---|---|---|
| off → dynisf ΔTIR | +6.6 | +6.1 |
| off → dynisf ΔTBR | −11.4 | −10.9 |
| off → dynisf ΔLBGI | −2.95 | −2.95 |
| autoisf → dynisf Δпадение | −6.4 | −6.3 |

Совпадение в пределах 0.5 п.п.; значимость p<0.0001 по всем ключевым метрикам.

## 5. Вывод

1. **На агрессивном профиле DynISF — лучший из трёх.** TIR +6.1 п.п., TBR −10.9 п.п., LBGI −2.95,
   доза −4.9 ЕД относительно off; против autoISF ещё сильнее (+7.7 / −12.6 / −3.27).
2. **Механизм — торможение.** Profile-sens DynISF поднимает ISF при низкой глюкозе и гасит
   гипогликемию, которую агрессивный профиль создаёт у off/autoISF; при этом общая доза падает.
3. **Граница применимости:** на правиле 1700/TDI DynISF платит TBR (A15), с вариативностью
   проигрывает autoISF по TBR/LBGI (A18). Его преимущество — именно на слишком агрессивном профиле.

## 6. Ограничения

1. CF из модели — derived-величина с известным расхождением в 2.4× (A3), а не клиническая истина.
2. Один сценарий, без вариативности, отказов и ошибок профиля.
3. Возмущаются только параметры всасывания.
4. Это не клинический вывод.
