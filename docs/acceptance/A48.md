# A48 — полная Wendt-PD: попытка реализации и блокер единиц

Дата: 2026-11-27
Статус: **negative / blocked**. Прототип собрал все уравнения и таблицы 2–5, но равновесное
состояние не соответствует протоколу; supplement S1–S10 недоступен. Подгонять параметры под
ожидаемую глюкозу — фит. Модель не добавлена.

## 1. Что сделано

Реализованы уравнения Wendt 2017 (PMC5951032): инсулиновая PK (двухкомпартментная, `tmax`,
`ClF,I`), глюкагоновая PK (`k1`, `k2`, `ClF,C`, `Cb`), PD (`Q1/Q2`, `x1–x3`, `GGG` с
`Emax/CE50/SE`, `F01`, `GGNG=6`, `V=160 мл/кг`). Параметры — Table 2, 3, 5 для 8 субъектов.
Протокол: инсулиновый болюс, при глюкозе ≤ порога — экзогенный глюкагон 0/100/200/300 мкг.

## 2. Что показали тесты

| Проверка | Ожидание | Факт |
|---|---|---|
| Глюкоза натощак (нет болюса) | 5–8 ммоль/л | **2.2 ммоль/л (40 мг/дл)** |
| Стабильность натощак | дрейф <0.3 | стабильна, но на 2.2 |
| Болюс 3 ЕД | заметное падение | падение **0.23 ммоль/л** |
| Дозозависимость глюкагона | рост с дозой | не проверить: база вне физиологии |

## 3. Почему это блокер, а не баг кода

1. **Единицы/определения не сходятся.** При `F01=14.2`, `Emax=56.4`, `Cb=10.7`, `CE50=436`
   базальная EGP ≈ 7.2 мкмоль/кг/мин, а `F01` один больше этого; равновесие уходит ниже 4.5,
   где `F01` масштабируется, и садится на 2.2. Либо `F01/Q1/V` определены иначе, либо
   `F01` — не та величина, что в Table 5.
2. **Supplement недоступен.** S1 (вес пациентов), S2 (приоры), S3–S10 (параметры фолдов) —
   PDF закрыт publisher/Cloudflare. Без S1 нельзя даже привести дозы и объём к пациенту.
3. **Формула insulin-PK в HTML искажена.** В accepted PDF она читается как
   `I = (1/tmax)·X2/(W·Cl)·10^6 + Ib`; размерность сходится, но без supplement нет уверенности,
   что множитель и `Cl` — именно те.
4. **Нет оцифрованных кривых.** Валидировать модель по графикам «на глаз» = фит.

## 4. Решение

- Прототип **удалён**; в репозитории нет модели, которая не проходит собственный steady-state.
- Полная Wendt-PD остаётся **blocked** до получения S1–S10 или авторских данных.
- `hypo_reb` остаётся blocked (A32); экзогенный rescue не реализован (A47).
- Критерий будущей реализации: fasting 5–8 ммоль/л, болюс даёт падение к ~70 мг/дл, глюкагон
  100/200/300 даёт монотонный дозозависимый рост; иначе не принимать.

## 5. Что разблокирует

- supplement S1–S10 (вес, приоры, параметры фолдов) или авторские данные;
- точная формула insulin-PK и определения `F01`, `Q1`, `V`;
- оцифрованные кривые глюкозы после 0/100/200/300 мкг для валидации.

## 6. Ограничения

1. Это не отказ от модели Wendt, а отказ от её reconstructions без данных.
2. Значения Table 2/3/5 взяты из открытого текста; ошибок транскрипции не исключаю.
3. Модель не интегрирована в AAPS и не должна использоваться для клинических выводов.

## 7. Воспроизведение

Прототип удалён; уравнения и параметры зафиксированы в этом отчёте и в A32/A47. Для повторной
попытки нужны S1–S10.
