# A22 — поведенческий слой в объявленном сценарии (перекус + ошибка объявления)

Дата: 2026-11-26
Статус: **принят**. Слой не меняет вывод A2 об autoISF в этом сценарии; абсолютный контроль
почти не сдвигается, значимость LBGI/падения ослабевает.

## 1. Постановка

30 субъектов, сценарий `announced-snack`: 8 ч, основные приёмы 50 г в 2 ч и 5 ч, перекус 20 г в
4 ч, еда объявлена. Два прогона: без слоя и с `--behaviour`; плечи autoISF `off`/`on`, парная
статистика. 60 прогонов на прогон, 52 и 46 с.

Слой добавляет:

- вероятность объявления основного приёма 80 %, перекуса 35 %;
- ошибку подсчёта углеводов CV 25 % (логнормально, среднее 1.0);
- rescue-углеводы при CGM ≤ 70 мг/дл (порог, рефрактерность 45 мин, 4–90 г, биодоступность 0.83);
- недельный дрейф ISF/CR (`weekly_factors`, 5.8 % CV для ISF) — реализован и покрыт тестом, но
  в 8-часовом сценарии не активен (нужен прогон ≥ 7 дней).

Параметры — из TimSim (MIT) и его источников; постраничная сверка — TODO.

## 2. Что сделал слой

Средние на прогон (8 ч):

| Плечо | объявлено | не объявлено | rescue, шт / г |
|---|---|---|---|
| off, без слоя | — | — | 0 / 0 |
| off, с слоем | 2.1 | 0.9 | 0.3 / 6.2 |
| on, без слоя | — | — | 0 / 0 |
| on, с слоем | 2.1 | 0.9 | 0.3 / 6.1 |

Сценарий гипергликемический (TIR ≈ 62 %, TBR ≈ 2 %), поэтому rescue почти не срабатывает:
0.3 события и ~6 г за 8 ч. Основной эффект слоя здесь — не rescue, а то, что ~0.9 приёма из 3
остаются необъявленными.

## 3. autoISF on/off: без слоя → с слоем

| Поле | без слоя | с слоем |
|---|---|---|
| ΔTIR | **+3.1 п.п. (p=.0003)** | **+3.0 п.п. (p=.0003)** |
| ΔTBR<70 | −0.2 (p=.10) | −0.2 (p=.11) |
| ΔLBGI | −0.038 (p=.085) | **−0.028 (p=.48)** |
| Δдоза | +0.65 U | +0.69 U |
| ΔSMB | −2.3 (p=.007) | **−3.4 (p=.0002)** |
| Δинсулин в падении | +4.5 п.п. (p=.0003) | **+2.7 п.п. (p=.055)** |

Абсолютные значения: TIR off/on 0.617/0.648 → 0.616/0.645; TBR 0.023/0.021 → 0.022/0.020;
LBGI 0.684/0.647 → 0.686/0.658.

## 4. Вывод

1. **Вывод A2 об autoISF устойчив к поведенческому слою:** преимущество по TIR (+3.0 п.п.,
   p=.0003) и снижение SMB (−3.4, p=.0002) сохраняются; абсолютный TIR/TBR почти не меняется.
2. **Значимость LBGI и доли инсулина в падении ослабевает** (p=.48 и p=.055). В этом сценарии
   мало гипогликемий, а rescue сглаживает низкие значения; для утверждений о LBGI в
   объявленных сценариях нужен сценарий с более частыми низкими.
3. Перекус и ошибка объявления не переворачивают сравнение алгоритмов; они меняют
   распределение объявленных углеводов (0.9 из 3 приёмов не объявлены), но не ранг.
4. Недельный дрейф ISF/CR реализован, но на 8 ч не влияет; его эффект нужно проверять на
   многодневном сценарии.

## 5. Ограничения

1. Один перекус, 8 ч, гипергликемический профиль; rescue почти не активен.
2. Один seed; без M3-вариативности и расширенной когорты.
3. Параметры поведения — TimSim и его источники; постраничная сверка TODO.
4. Сценарий объявленный; FCL-сценарии слой использует только для rescue (A21).
5. Недельный дрейф ISF/CR не включён в прогон (нужен ≥ 7 дней).
6. Это не клинический вывод.
