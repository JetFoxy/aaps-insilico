# M0 — приёмка регистра параметров

Дата: 2026-11-10
Статус: **принят** с одним зафиксированным ограничением (вектор параметров S2017 проприетарен).

## 1. Что требовалось

По спеке §6, M0: «регистр параметров: число, источник, страница». Приёмка: «нет числа без
ссылки, пробелы перечислены».

## 2. Проверка

| Требование | Результат |
|---|---|
| Источники перечислены | ✅ 4 работы, DOI + PMCID |
| Уравнения модели зафиксированы | ✅ Appendix S2017, 6 блоков |
| Каждое число имеет источник | ✅ `docs/registry/parameters.csv`, колонка `source` |
| Пробелы перечислены | ✅ §5 `parameters.md`, 8 позиций с адресом поиска |
| Числа не подобраны | ✅ отсутствующие помечены `todo`, а не заполнены оценкой |

Всего в регистре 68 строк: 13 `published`, 55 `todo`. Ни одной строки со значением без
источника.

## 3. Ограничение, которое надо принять до M1

Индивидуальные параметры модели (`kp1`, `kp2`, `kp3`, `Vm0`, `Vmx`, `Km0`, `p2U`, `k1`, `k2`,
`m1`–`m4`, `ka1`, `ka2`, `kd`, `τ`, `kabs`, `kmax`, `kmin`, `α`, `β`, `b`, `c`, `f`, `ke1`,
`ke2`, `Fcns`, `VG`, `VI`, `r1`, `r2`, `ξ`, `kH`, `n`, `ρ`, `σ`, `δ`, `kh1`–`kh3`, `Ts`, `Gb`,
`Gpb`, `Gtb`, `Ipb`, `Ilb`, `Hb`) **не опубликованы**. Они входят в проприетарный T1DMS
(MathWorks/MATLAB) как вектор на субъекта. Открытые статьи дают уравнения, демографию и
величины эффекта, но не эти числа.

Следствия, зафиксированные в спеке и отчёте:

1. Стенд строит «UVA/Padova-подобную по Visentin et al. 2018» модель, а не официальную
   популяцию. Название «UVA/Padova simulator» в отчётах запрещено.
2. Для M1 нужен один из двух путей:
   - **derived**: взять открытый производный набор (`simglucose 0.2.11`, `patient_params.csv`) —
     это параметры S2008-модели; в регистре и отчётах они будут помечены `derived`, а не
     `published`;
   - **identification**: восстановить параметры по опубликованным сводкам (Table 1 S2008/S2017)
     — это отдельная задача M2, и она должна быть описана как таковая.
3. Ни один из путей не даёт права называть результат официальной популяцией FDA.

## 4. Что это меняет в плане

- M1 может стартовать на S2017-уравнениях с `derived`-параметрами; приёмка M1 (стационар = Gb,
  баланс пищи 1 %, отклик на 60 г) от параметров популяции не зависит.
- M2 (популяция по маргиналам) должна явно указать, что маргиналы — из Table 1 S2017, а
  ковариационная структура — `derived`/идентифицированная.
