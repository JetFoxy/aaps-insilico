# A18 — DynISF на расширенной когорте с вариативностью M3

Дата: 2026-11-12
Статус: **принят**. Эффект A16 подтверждается на 120 субъектах.

## 1. Постановка

- 120 субъектов (30 базовых + 3 копии), вариативность M3 (классы SI + рассвет +1.5 EGP).
- FCL 24 ч, 5-мин каденс, 30-мин темпы, профиль по правилу 1700/TDI.
- Плечи `off`, `autoisf`, `dynisf`, одинаковый сид CGM; парная статистика.
- 360 прогонов, 431 с.

## 2. Средние

| Плечо | TIR | TBR<70 | LBGI | SMB | Доза | В падении |
|---|---|---|---|---|---|---|
| off | 0.573 | 3.6 % | 1.04 | 153 | 49.4 | 0.353 |
| autoisf | 0.588 | 4.5 % | 1.29 | 131 | 51.8 | 0.404 |
| dynisf | 0.582 | 5.0 % | 1.49 | 119 | 51.3 | 0.324 |

## 3. Парные разности (n=120)

| Сравнение | ΔTIR | ΔTBR | ΔLBGI | Δдоза | Δпадение |
|---|---|---|---|---|---|
| off → autoisf | **+1.5 п.п. (p<0.0001)** | +0.9 (p<0.0001) | +0.25 | +2.42 | +5.1 п.п. |
| off → dynisf | **+0.9 п.п. (p<0.0001)** | +1.4 (p<0.0001) | +0.45 | +1.95 | −2.9 п.п. |
| autoisf → dynisf | −0.6 (p=0.058) | +0.5 (p=0.069) | +0.20 (ns) | −0.47 (p=0.009) | **−8.0 п.п. (p<0.0001)** |

## 4. Сравнение с A16 (30 субъектов, та же вариативность)

| Метрика | A16, n=30 | A18, n=120 |
|---|---|---|
| off → dynisf ΔTIR | +1.0 | +0.9 |
| off → dynisf ΔTBR | +1.3 | +1.4 |
| off → dynisf ΔLBGI | +0.41 | +0.45 |
| autoisf → dynisf Δпадение | −8.5 | −8.0 |

Совпадение в пределах 0.5 п.п.; на n=120 всё значимо, кроме ΔLBGI и ΔTIR/ΔTBR между autoISF и
DynISF (p≈0.06).

## 5. Вывод

1. **При вариативности оба алгоритма улучшают TIR** относительно off: autoISF +1.5 п.п., DynISF
   +0.9 п.п. Агрессивность вверху помогает, потому что база гипергликемична.
2. **autoISF здесь лучше по безопасности:** TBR +0.9 против +1.4 у DynISF, LBGI +0.25 против +0.45.
3. **DynISF сильнее тормозит:** инсулин в падении на 8.0 п.п. ниже, чем у autoISF.
4. «DynISF выигрывает по всем метрикам» остаётся только на агрессивном CF из модели (A16); на
   правиле и на правиле+вариативности он проигрывает autoISF по TBR/LBGI.

## 6. Ограничения

1. Возмущаются только параметры всасывания; чувствительность к инсулину не варьируется.
2. Один seed вариативности на субъекта.
3. Профиль по правилу 1700/TDI.
4. Это не клинический вывод.

## 7. Воспроизведение
