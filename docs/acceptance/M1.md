# M1 — приёмка ядра

Дата: 2026-11-10
Статус: **принят** с ограничениями, перечисленными в §4.

## 1. Что требовалось

По плану §3, M1: «уравнения приложения и юнит-тесты». Приёмка: на базале стационарное
состояние возвращает `Gb`; баланс массы пищи (всосанное равно `f·доза` в пределах 1 %);
состояния неотрицательны; болюс по CR на 60 г углеводов даёт отклик в диапазонах §1 плана.

## 2. Что реализовано

`python/simcore/model.py` — 13 состояний:
`Qsto1, Qsto2, Qgut, Gp, Gt, Ip, X, I1, XL, Il, Isc1, Isc2, Gsub`.

Уравнения — Appendix S2017 (Visentin 2018): глюкозный и инсулиновый блоки, желудок/кишечник с
`kempt()`, EGP, утилизация с `Uid`, почечная экскреция, подкожный инсулин (`Isc1`, `Isc2`,
`ka1`, `ka2`, `kd`), подкожная глюкоза (`ksc`).

Хуки S2017 присутствуют, но по умолчанию выключены, потому что их параметры не опубликованы:
`kp1(t)`, `kp3(t)`, `Vmx(t)`, `kir(t)` (множители = 1.0), `risk(G)` (`r1 = 0`), задержка
`τ` (нет). Глюкагон (`H`, `SRHs`, `XH`) не входит в 13 состояний: его параметры — `TODO` в
регистре; включается на M3.

Параметры — `derived` (simglucose, S2008/S2013): `python/simcore/params/vpatient_params.csv`,
происхождение — `PROVENANCE.md`.

## 3. Результаты

Субъект `adult#001`, `Gb = 138.56 мг/дл`, базальная инфузия `u2ss·BW/6000`.

| Тест | Порог | Факт |
|---|---|---|
| Стационар на базале, 24 ч | `< 1 мг/дл` | **6.5·10⁻¹⁰ мг/дл** |
| Баланс пищи, 60 г, 12 ч | ошибка `< 1 %` | **0.000 %** (54 000.0 мг против `f·dose = 54 000.0`) |
| Неотрицательность состояний, 6 ч с болюсом | `≥ 0` | минимум **−4.6·10⁻¹⁰** (численный ноль) |
| Пик глюкозы над базалом, 60 г + болюс по CR, 5 взрослых | 68 ± 30 мг/дл | **92.5** (57.0–115.7) |
| Пик инсулина, те же | 185 ± 108 пмоль/л | **285.2** (211.4–344.3) |

CR для теста — **10.5 г/ЕД** (S2008 Table 1, та популяция, из которой взяты `derived`-параметры).
С CR 15.9 (S2013 Table 1) пик глюкозы 107.1 мг/дл выходит за 68 + 30: это ожидаемо, потому что
S2008-субъекты имеют `Gb ≈ 138` и другую чувствительность, а CR — population value, не
индивидуальный. Индивидуальный CR по правилу S2013 — задача M2.

## 4. Ограничения (зафиксированы, не скрыты)

1. **Параметры `derived`, не S2017.** `Gb` у субъектов 133–152 мг/дл, у S2017 — 119.1 мг/дл
   (Table 1). Поэтому пики сравниваются с диапазоном S2017, но популяция другая; это
   сознательная аппроксимация до M2.
2. **Глюкагон выключен.** `ξ, n, ρ, σ, δ, kH` — `TODO`; без них нет контррегуляции, M3.
3. **Время-зависимые члены выключены.** `kp1(t)`, `kp3(t)`, `Vmx(t)`, `kir(t)` — единицы;
   суточная вариация и рассвет — M3.
4. **`τ` не реализована.** Подкожный инсулин идёт по S2013-модели (`ka1`, `ka2`, `kd`);
   S2017-задержка `τ` и PK аналогов — M5.
5. **`kempt()` использует `Dbar = размер текущего приёма`,** а не «содержимое желудка на момент
   старта + доза». Для одиночных приёмов это эквивалентно; для перекрывающихся приёмов — M7.
6. **Один решатель:** `LSODA`, `rtol=1e-8`, `atol=1e-10`, `max_step=1 мин`. Детерминизм по
   сидам в M1 не проверяется — здесь нет стохастики.
