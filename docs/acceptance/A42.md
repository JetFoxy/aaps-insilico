# A42 — source review: кинетика подкожного инсулина

Дата: 2026-11-27
Статус: **принят как source review + пред-регистрация**. Модель пока не менялась. Найден
источник на параметры быстрого аналога (lispro), которых в стенде нет; предложен вариант v2
с фиксированными до прогона ожиданиями.

## 1. Проблема

A41 показал: оставшийся longest-low (150 мин) — поздний низ после SMB-поезда, а A3 — надир
~365 мин для 1 ЕД. Обе вещи указывают на кинетику инсулина. Вопрос: это свойство модели,
которое можно исправить по источнику, или предел?

## 2. Что сейчас в модели

`simcore/model.py` реализует подкожный компартмент S2008:

```
İsc1 = −(kd + ka1)·Isc1 + u(t)
İsc2 = kd·Isc1 − ka2·Isc2
RaIsc = ka1·Isc1 + ka2·Isc2
```

Задержка `τ` из S2017 **отсутствует** (`tau` нет в параметрах субъекта, docstring: «present but
inactive»). Значения `ka1/ka2/kd` — из derived-вектора S2008, т.е. кинетика **регулярного**
инсулина. Пример `adult#001`: `ka1 0.0019`, `ka2 0.0078`, `kd 0.0152`, τ = 0; надир пробы
1 ЕД — **365 мин**. `child#005`: `ka1 0.0037`, `ka2 0.0199`, `kd 0.0197`; надир 184 мин.

В мосту при этом используется **Lyumjev** (быстрый аналог). То есть пациентская модель
абсорбирует инсулин как регулярный, а алгоритм дозирует аналог.

## 3. Источник

S2017 (Visentin 2018, Appendix A16–A17) использует модель быстрых аналогов Schiavon et al.
(ссылка 32), идентифицированную на 116 пациентах с T1D. Открытый текст с популяционными
параметрами — Faggionato, Schiavon, Dalla Man 2021 (Metabolites, PMC8069884, CC BY):

| Параметр | Популяционное значение | Разброс (individual, Table 3) | Источник |
|---|---|---|---|
| `τ` | **5.62 мин** (ω 0.731) | 0.75–21.9 | Faggionato 2021, Table 2/3 |
| `ka1` | **0.000134 /мин** (ω 1.86) | 0.000079–0.00824 | там же |
| `ka2` | **0.0128 /мин** (ω 0.322; BMI-ковариата −0.0865 на м²/кг) | 0.00418–0.0313 | там же |
| `α = kd − ka2` | **0.0155 /мин** (ω 1.02) | 0.00364–0.116 | там же |
| `kd` | **0.0283 /мин** (вычислено: ka2 + α) | — | вывод |
| `VI` | 0.135 л/кг | 0.074–0.29 | там же |
| `ke` | 0.113 /мин | 0.046–0.195 | там же |

Структура — та же трёхкомпаartmentная схема (`Isc1`, `Isc2`, `Ip` + задержка `τ`), что в
Appendix A16–A17. Это не «другая модель», а параметры и недостающая задержка для той же схемы.

## 4. Сравнение с текущими значениями

| Параметр | Сейчас (S2008, adult#001) | Lispro (источник) | Отношение |
|---|---|---|---|
| `τ` | 0 (нет) | 5.62 мин | отсутствует |
| `ka1` | 0.0019 | 0.000134 | **14× быстрее** |
| `ka2` | 0.0078 | 0.0128 | 0.61× |
| `kd` | 0.0152 | 0.0283 | 0.54× |

Разница не косметическая: текущая схема имеет более быстрый малый путь (`ka1`), но медленнее
диссоциирует и медленнее отдаёт из второго компартмента — хвост длиннее.

Важная оговорка: надир 365 мин — это **композит** абсорбции и действия (m1–m4, p2u, ki), а не
только подкожного компартмента. Поэтому замена sc-параметров может сократить хвост, но не
обязана убрать все 365 мин; это проверяется прогоном, а не предполагается.

## 5. Пред-регистрация варианта v2 (A43)

До прогона фиксируются:

1. **Что меняется:** только подкожный компартмент: `τ`, `ka1`, `ka2` (с BMI-ковариатой), `kd`
   по опубликованным популяционным значениям. Индивидуальные значения — детерминированные
   lognormal-отклонения с опубликованными ω (seed = crc32(имя)), как в остальной когорте.
   Действие инсулина (`m1–m4`, `p2u`, `ki`, `Vmx`) не трогается.
2. **Как:** флаг `--insulin-pk lispro` (по умолчанию — текущая S2008, чтобы старые прогоны
   воспроизводились); `τ` реализуется сдвигом расписания на `τ` минут.
3. **Ожидания (направленные, не пороги подгонки):**
   - пик скорости появления инсулина в плазме наступает раньше;
   - надир пробы 1 ЕД (A3-метод) короче;
   - longest-low в A40-плече не больше, чем сейчас (150 мин);
   - `diurnal` не хуже (67.5), TIR не ниже.
4. **Провал ожиданий — результат:** если хвост не сокращается или TIR падает, v2 не
   включается по умолчанию, а фиксируется как отрицательный результат.

## 6. Ограничения

1. Источник — **lispro** (Humalog), не Lyumjev; оба быстрые аналоги, но кривые разные.
2. Популяция Schiavon/Faggionato — 116 взрослых T1D, не S2017-вектор; перенос на derived-когорту
   (включая детей) — допущение.
3. BMI-ковариата для `ka2` требует BMI субъекта; в derived-когорте есть BW, но рост/IMT нет —
   нужно либо принять IMT 25, либо использовать только популяционное `ka2` (это будет оговорено).
4. S2017-вектор по-прежнему проприетарный; страничная сверка S2017 Appendix для наших уравнений
   остаётся TODO.
5. Модель действия инсулина не меняется; если хвост в основном от неё, v2 не поможет — это и
   покажет A43.

## 7. Решение

- Источник найден и достаточен для **варианта**, но не для смены базлайна: значения не из S2017
  и не для Lyumjev.
- Реализация — только за флагом, с пред-регистрированными ожиданиями и отдельным отчётом A43.
- Реестр параметров обновлён: `ka1/ka2/kd/tau` получают источник и статус `published (lispro
  population)`, вместо `todo`.
