# A46 — деривация параметров Lyumjev из label: не прошла критерий

Дата: 2026-11-27
Статус: **negative, независимо подтверждён**. Фит к опубликованной кривой сходится по точкам
1–5 ч, но не воспроизводит раннюю фазу (Tmax и 50 % Cmax). Пред-регистрированный критерий не
выполнен → вариант `--insulin-pk lyumjev` не добавляется. Colmegna 2024 описывает тот же
waterbed-эффект и предлагает другую структуру (см. §6a).

## 1. Вопрос

Можно ли вывести параметры подкожной кинетики для Lyumjev (lispro-aabc) из открытой кривой
концентрации, не подгоняя под глюкозные исходы?

## 2. Данные

Lyumjev US prescribing information, §12.2 (средние, здоровые субъекты, 15 ЕД):

| Время, ч | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| Концентрация, пмоль/л | 0 | 555 | 450 | 205 | 73 | 28 |

Дополнительные опубликованные метрики: Tmax **57 мин**, 50 % Cmax за **13 мин**, действие
короче Humalog (~4 ч, StatPearls).

## 3. Метод и пред-регистрация

Та же трёхкомпартментная схема (`Isc1`, `Isc2`, `Ip`, задержка `τ`). `ke = 0.113 /мин`
зафиксирован по популяции lispro; `BW = 70 кг`; свободны `τ`, `ka1`, `ka2`, `α`, `VI` в
опубликованных индивидуальных границах lispro. Фит — относительные остатки по точкам 1–5 ч,
несколько стартов, детерминированно.

Критерий приёмки (до фита): max относительная ошибка ≤15 % в каждой точке **и** Tmax 45–70 мин.

## 4. Результат

| Параметр | Значение |
|---|---|
| `τ` | 25.0 мин |
| `ka1` | 1.0e-6 /мин (нижняя граница) |
| `ka2` | 0.0172 /мин |
| `α = kd − ka2` | 0.0160 /мин |
| `kd` | 0.0332 /мин |
| `VI` | 0.152 л/кг |
| Max относительная ошибка | **3.5 %** |
| Tmax модели | **77 мин** (label 57) |
| 50 % Cmax | **43 мин** (label 13) |
| Критерий | **не выполнен** (Tmax > 70, ранняя фаза) |

## 5. Почему это отрицательный результат

1. **Точки 1–5 ч описываются хорошо, ранняя фаза — нет.** Модель с фиксированным `ke` и
   медленным `ka1` не может дать 50 % Cmax за 13 мин; фит выбирает `ka1` на нижней границе.
2. **Tmax 77 против 57** — вне пред-регистрированного окна. Подгонять `ke` или расширять
   границы после результата было бы подгонкой под желаемое.
3. **Кривая label — средняя по здоровым, 15 ЕД, BW неизвестен.** Даже хороший фит не даёт
   субъект-специфичных параметров; это была бы `derived`-аппроксимация с большой оговоркой.
4. **«45m» в профиле AAPS — не PK-параметр.** Это настройка пика для алгоритма; использовать её
   как `τ`/`ka` нельзя.

## 6a. Независимое подтверждение: Colmegna 2024

Colmegna, Diaz, Garcia-Tirado, DeBoer, Breton (UVA), *J Diabetes Sci Technol*
2024;18(3):676–685 (PMC11089876) моделировали URLi внутри UVA/Padova по клэмп-данным
**Linnebjerg et al., Clin Pharmacokinet 2020;59:1589** (Plum-Mörschel — соавтор; не первый
автор, как иногда цитируют). Они получили ровно тот же waterbed:

- параметры двухкомпартментной sc-PK были идентифицированы для lispro;
- простое ускорение (масштабирование всех параметров) **не** воспроизводит одновременно пик и
  хвост URLi: уменьшение ошибки пика увеличивает ошибку хвоста;
- вывод авторов: это структурное ограничение одной цепочки, а не подбор `ke`/границ.

Они меняют структуру: диффузию из `Isc1` в `Isc2` делают Michaelis–Menten:

```
İsc1 = −ka1·Isc1 − kd·KM/(KM + Isc1)·Isc1 + u(t−τ)
İsc2 = −ka2·Isc2 + kd·KM/(KM + Isc1)·Isc1
```

и публикуют относительные коэффициенты для URLi: `ka1×13`, `kd×1.45`, `τ×0.5`, `KM×2.1`
относительно lispro. Это кандидат на структуру, проходящую и пик, и хвост.

**Биодоступность:** у URLi она около **65 %** для живота, плеча и бедра; скорость абсорбции и
ранний эффект от места введения не зависят (Linnebjerg 2020). Если модель принимает
биодоступность за 1, хвост и масштаб кривой искажаются — это отдельный параметр, не косметика.

**Чего не хватает:** абсолютного `KM_LIS` и полного набора параметров; в тексте только
отношения. `ka2` в отношениях не указан — приходится предполагать, что он не меняется. Без них модель не собрать, а подбирать `KM` под label-кривую — снова деривация без
независимых ограничений. Поэтому вариант остаётся blocked, но блокер уточнён: не «нет модели»,
а «есть структура-кандидат без абсолютных параметров».

**A49:** ограниченная деривация в этой структуре (свободны только `KM_LIS` и `VI`) не прошла
критерий: Tmax 53 и 50 % Cmax 17.5 в окне, но ошибка 25.5 % против ≤10 %; на синтетике `KM`
не восстанавливается. Нужны абсолютные параметры, а не дополнительный fit.

## 6. Решение

- `--insulin-pk lyumjev` **не добавляется**; lispro-вариант (A42/A43) остаётся единственным
  источником-backed PK-вариантом, и он opt-in.
- Деривация сохранена как инструмент (`python/runner/derive_lyumjev.py`) и как отрицательный
  результат: для Lyumjev нужна либо опубликованная модель абсорбции (не найдена), либо более
  богатая структура/данные, а не подгонка текущей.
- Реестр не пополняется значениями Lyumjev: статус остаётся `todo` для S2017-вектора.

## 7. Ограничения

1. Средняя кривая, здоровые, одна доза; межиндивидуальная вариабельность неизвестна.
2. `ke` и `VI` взяты из популяции lispro; для URLi они могут отличаться.
3. Ранняя фаза (0–60 мин) в фите отсутствует, кроме опубликованных метрик Tmax/50 %.
4. Числа модели — не клинические; это стенд.

## 8. Воспроизведение

```bash
cat out/lyumjev_fit.json
```
