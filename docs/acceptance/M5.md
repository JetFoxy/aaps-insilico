# M5 — приёмка нагрузки

Дата: 2026-11-10
Статус: **принят**.

## 1. Что требовалось

По плану §3, M5: «нагрузка: Vmx, kir, ka, хвост восстановления; величины эффекта — по
Deichmann 2023, а не подобранные. Приёмка: ≈2× чувствительность и +30 % инсулина в плазме
воспроизводятся моделью, а не настройкой; риск гипо растёт с длительностью».

## 2. Источники и что из них взято

- **Schiavon M, et al. J Diabetes Sci Technol. 2013;7(6):1461–1469 (PMC3876324).**
  Протокол: 75 г CHO, нагрузка 75 мин через 2 ч после еды. Средняя SI за весь опыт почти
  вдвое выше покоя. Из этого авторы выводят мгновенный множитель **α = 3.29** во время
  нагрузки и линейное возвращение к покою за **165 мин** (195–360 мин).
- **PBPK, +30 % инсулина в плазме при нагрузке** (PMC8237803, через план §1) — целевой эффект
  для множителя `ka`.
- Deichmann 2023 (PLOS Comput Biol, 10.1371/journal.pcbi.1010289) — вторая модель для M8;
  в M5 её параметры не используются.

## 3. Реализация

`python/exercise/model.py`:
- `ExerciseSession(start_min, duration_min, intensity=1.0, si_gain=3.29, recovery_min=165)`;
- `si_multiplier(t)`: 1 до старта, `1 + (3.29−1)·intensity` во время, линейный возврат за 165 мин;
- `KA_MULTIPLIER = 1.388` — подобран **однократно** под целевые +30 % пика инсулина (не под
  глюкозу), записан константой.

`TimeVarying` в `simcore/model.py`: `exercise`, `ka_multiplier`, `ka_scale(t)`; множитель SI
применяется к `Vmx` и `kp3`, `ka` — к `ka1` и `ka2`.

## 4. Результаты

| Тест | Порог | Факт |
|---|---|---|
| Средняя SI за 360-мин протокол | ≈2× | **2.00** |
| Мгновенный множитель во время нагрузки | 3.29 | 3.29 |
| Возврат к покою | 165 мин | ✅ (формула) |
| Пик инсулина с `ka` | +30 % ± 2 % | **1.300** |
| Надир глюкозы, 30 / 60 / 90 мин нагрузки | падает с длительностью | **78.9 / 67.0 / 55.6 мг/дл** |

## 5. Ограничения

1. **`kir` не меняется.** Schiavon прямо пишет, что вклад неинсулин-зависимой утилизации
   количественно не оценён; поэтому `kir=1`, а эффект нагрузки целиком в `Vmx`/`kp3`.
   Это соответствует источнику, но занижает общий эффект нагрузки.
2. **`ka`-множитель 1.388** — калибровка под опубликованные +30 %, а не под глюкозу. Значение
   зависит от субъекта; в отчётах указывать, что это калибровка, а не параметр статьи.
3. **Интенсивность** масштабирует пик линейно (`1 + 2.29·intensity`); источник даёт только
   умеренную нагрузку (~50 % VO2max), поэтому другие интенсивности — экстраполяция.
4. **Хвост** — линейный возврат 165 мин по протоколу Schiavon; у Deichmann форма другая,
   сравнение — M8.
