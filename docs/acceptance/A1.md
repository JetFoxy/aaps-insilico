# A1 — сравнение autoISF on/off в замкнутом контуре

> **Поправка 2026-11-11.** В контуре найден баг: SMB-болюсы попадали в журнал доз и в IOB, но
> не подавались в физиологическую модель — пациент получал только базал (в типичном прогоне 64 %
> записанной дозы были «фантомными»). Исправлено: доставленные болюсы идут в `Schedule.boluses`
> следующего сегмента; регрессионный тест `test_smb_boluses_reach_the_physiology` и
> `test_blocked_boluses_raise_glucose`. Отчёт пересчитан на исправленном контуре; старые числа
> сохранены в `out/legacy_phantom/`.


Дата: 2026-11-11
Статус: **демонстрация**, не вывод. Один сценарий, 5 субъектов.

## 1. Зачем

Главная цель стенда — сравнивать варианты алгоритма при одинаковых сценариях. Это первый такой
прогон: тот же субъект, тот же сценарий, тот же сид CGM; меняется только `enable_auto_isf`.

## 2. Постановка

- 5 подростков (`adolescent#001–005`), 24 ч, 3 приёма по 50 г (7:00/13:00/19:00), FCL
  (углеводы не объявлены).
- Профиль алгоритма: CR по M2 (правило S2008), ISF = 1700/TDI, target 110 мг/дл, SMB разрешён.
- autoISF — настоящий `OpenAPSAutoISFPlugin.autoISF()` через мост, на каждом цикле.
- Сид CGM — `crc32(имя)`, одинаковый для on и off.
- Скрипт: `python/runner/autoisf_compare.py --limit 5` (~62 с).

## 3. Результат (среднее по 5 субъектам)

| Метрика | autoISF off | autoISF on | Δ |
|---|---|---|---|
| TIR 70–180 | 0.751 | 0.731 | **−0.020** |
| TBR <70 | 0.037 | 0.057 | **+0.020** |
| TBR <54 | 0.010 | 0.016 | +0.006 |
| LBGI | 1.023 | 1.485 | **+0.46** |
| SMB/сутки | 91.8 | 78.6 | −13.2 |
| Суммарная доза, ЕД | 33.98 | 34.98 | **+1.00 (+2.9 %)** |
| Доля инсулина в падении | 0.336 | 0.403 | **+6.7 п.п.** |

По субъектам TIR: 1.00→1.00, 0.56→0.56, 0.77→0.77, **0.69→0.60**, 0.74→0.73. Весь агрегат
сдвигает один субъект (`adolescent#004`: TBR 5 %→15 %).

## 4. Как это читать

- autoISF **не улучшил TIR** (−2 п.п.) и **сдвинул риск в сторону гипогликемии**: TBR 3.7 %→5.7 %,
  LBGI 1.02→1.49. Это уже не «нулевой» эффект, как в первом (сломанном) прогоне.
- Доза выросла всего на 2.9 % (33.98→34.98 ЕД), а число SMB упало на 13 — то есть SMB стали
  крупнее, а не чаще.
- Доля инсулина на падающей глюкозе +6.7 п.п.
- Весь сдвиг держится на одном субъекте из пяти: для выводов нужна матрица, и она в A2.

Это не клинический вывод: 5 субъектов, один сценарий, профиль без ошибок, FCL. Для выводов нужна
матрица (субъекты × сценарии × оба режима еды × ошибки профиля) и парная статистика; A1 —
доказательство, что стенд это умеет.

## 5. Ограничения

1. `mealCOB = 0` (FCL), объявленная еда в A1 не проверялась.
2. Профиль алгоритма — population-level (CR S2008, ISF 1700/TDI), не персонализированный.
3. Temp basal применяется на 1 цикл; IOB-журнал включает эти temp, но не 30-минутные плановые.
   Исправлено в A2 (`temp_mode="planned"`, `docs/acceptance/A2.md` §5).
4. Нет сценариев ошибки профиля и нагрузки; TBR взят из базового FCL.
5. Один сид на субъекта; разброс по сидам не оценивался.
