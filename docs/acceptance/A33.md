# A33 — абляция: шаблонная еда без M3 (22 суток)

Дата: 2026-11-26
Статус: **принят как эксперимент и как лучший fidelity-конфиг на сегодня**. 7/12 в конверте.
Не валидация. Парный анализ A34 подтверждает: `tail`, `diurnal`, `hypo_rec`, `hypo_reb`
улучшаются устойчиво по субъектам, а `cv`/`outcome` — по медиане, не у каждого.

## 1. Постановка

A29 (фиксированные 3×50 г, без M3) плюс только шаблон еды TimSim (7 приёмов, 5.2 в сутки,
292 140 записей OpenAPS Data Commons), **без** M3-вариативности. Остальное как A29: 30×22 суток,
drift 15 %, behaviour, compression 3.5/30 дней, чистый пин `74271a544b`.

Прогон нужен, чтобы разделить два изменения A31: шаблон еды и M3. Без абляции вывод «пробел был
артефактом расписания» не доказан.

## 3. Вывод

1. **Шаблон еды — основной источник улучшения.** Один шаблон (M3 off) даёт `tail` 8.32 → 4.86,
   `outcome` 44.9 → 30.2, `diurnal` 157.9 → 64.4, `cv` 40.5 → 35.3. Три больших приёма по 50 г
   действительно искажали распределительные подписи; это подтверждено абляцией, а не предположено.
2. **M3-вариативность в этом стенде ухудшает fidelity, а не улучшает.** От A33 к A31:
   `acf60` 0.522 → 0.716 (выход из конверта), `diurnal` 64.4 → 138.9 (дальше от конверта),
   `hypo_rec` 51.25 → 45.0 (выход вниз). Единственный выигрыш — `cv` 35.3 → 33.7.
   M3 полезна для проверки устойчивости алгоритма (A16/A18), но не для совпадения с реальными
   трейсами на этом окне.
3. **`hypo_rec` в конверте: 51.25 мин** (50–59). Rescue + реалистичная еда дают правильное
   восстановление без подгонки.
4. **`hypo_reb` 47.7 остаётся вне** (23.2–28.4); контррегуляции нет, см. A32.
5. **`diurnal` 64.4 — ближе всего к конверту (34.7–56.3), но всё ещё выше.** Оставшийся разрыв —
   суточный профиль модели, не расписание еды: шаблон убрал половину амплитуды, но пищевые
   пики всё ещё велики.
6. **`cv` 35.3 чуть выше 34.3**; `insulin_cv` 2.84 ниже конверта и зависит от драйвера (A30).

## 4. Ограничения

1. Шаблон — поведенческое распределение OpenAPS, не S2017 и не физиология.
2. 22 суток, 30 субъектов, один seed; без site failure.
3. `drift`/`insulin_cv` — калибровка оценщика (A30).
4. `diurnal`/`outcome` зависят от расписания приёмов; шаблон — один из возможных.
5. Числа с чистого пина `74271a544b`.
