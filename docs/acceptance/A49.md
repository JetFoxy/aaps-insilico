# A49 — ограниченная деривация Lyumjev в MM-структуре: negative

Дата: 2026-11-27
Статус: **negative**. MM-структура Colmegna и относительные коэффициенты опубликованы, но
свободных параметров всё равно больше, чем ограничений; fit к label-кривой не проходит
пред-регистрированный критерий. Вариант не добавляется.

## 1. Постановка

Использована структура Colmegna 2024 (PMC11089876):

```
İsc1 = −ka1·Isc1 − kd·KM/(KM + Isc1)·Isc1 + u(t−τ)
İsc2 = −ka2·Isc2 + kd·KM/(KM + Isc1)·Isc1
İp   = −ke·Ip + ka1·Isc1 + ka2·Isc2
```

Зафиксировано по публикациям:

- базовые lispro-параметры: `ka1 1.34e-4`, `ka2 0.0128`, `kd 0.0283`, `τ 5.62` (Schiavon
  2018/Faggionato 2021);
- отношения URLi: `ka1×13`, `kd×1.45`, `τ×0.5`, `KM×2.1` (Colmegna 2024);
- биодоступность `0.65` (Linnebjerg 2020, Clin Pharmacokinet 59:1589 — Plum-Mörschel соавтор);
- `ke 0.113`, `BW 70 кг`, доза 15 ЕД.

Свободны только `KM_LIS` и `VI`; fit к точкам 1–5 ч label с штрафами за Tmax и 50 % Cmax.
Пред-регистрация: max относительная ошибка ≤10 %, Tmax 50–65 мин, 50 % Cmax 8–20 мин.

## 2. Результат

| Метрика | Значение | Критерий |
|---|---|---|
| `KM_LIS` | 199 279 пмоль/кг | — |
| `KM_URLi` | 418 485 пмоль/кг | — |
| `VI` | 0.095 л/кг | в опубликованном диапазоне |
| Tmax | **53 мин** | 50–65 ✅ (label 57) |
| 50 % Cmax | **17.5 мин** | 8–20 ✅ (label 13) |
| Max относительная ошибка | **25.5 %** | ≤10 ❌ |

Проверка на синтетике: при истинных `KM=1500`, `VI=0.11` fit возвращает `KM≈318`,
`VI≈0.072`, ошибка 14.3 %; при других стартах ошибка до 54 %. То есть даже два свободных
параметра по пяти точкам не идентифицируются.

## 3. Вывод

1. **Структура помогает, но не спасает.** Tmax и 50 % Cmax попадают в окно, а хвост/точки —
   нет: ошибка 25.5 % против требуемых 10 %.
2. **Недоопределённость подтверждена.** Пять точек label + два метрик-штрафа не дают
   идентифицировать `KM/VI`; синтетика это показывает.
3. **Причина — та же, что в A48:** нужны абсолютные параметры (`KM_LIS`), supplement или
   авторские данные, а не дополнительные границы fit.
4. **Решение:** `--insulin-pk lyumjev` не добавляется. Инструмент `derive_lyumjev_mm.py`
   сохранён как negative-результат и проверка структуры.
5. **Рекомендация:** написать авторам Colmegna/UVA или дождаться публикации абсолютных
   параметров; альтернатива — использовать label-кривую только как validation target, не как
   источник параметров.

## 4. Ограничения

1. Label-кривая — средняя по здоровым, 15 ЕД; межиндивидуальная вариабельность неизвестна.
2. `ka2` в отношениях Colmegna не указан — принят неизменным; это допущение.
3. `VI` фитится, хотя в модели UVA/Padova он может быть фиксирован иначе.
4. `ke` фиксирован по lispro; для URLi не измерялся отдельно.
5. Числа — модельные, не клинические.
