# A37 — safety gate на 22 сутках: 660 subject-days на плечо

Дата: 2026-11-27
Статус: **принят как расширение A25**. Оба плеча fail по индивидуальным хвостам; шаблонная еда
вдвое снижает burden, но не делает плечо безопасным. Gate — скрин, не доказательство.

**Коррекция A38:** три субъекта (`child#001/004/009`) не имеют feasible CR и получали
fallback-профиль; их вклад — почти весь хвост ниже. Без них (n=27): fixed `<54` 141.6,
longest 160, TBR 0.163; template `<54` 27.3, longest 150, TBR 0.077. Вердикт fail сохраняется,
но по другому критерию. Подробности: A38.

## 1. Постановка

A25 считал gate на 1 сутках (30 subject-days). Здесь — **22 суток × 30 субъектов = 660
subject-days на плечо**, истинная плазменная глюкоза (не CGM). Два плеча:

- **fixed:** три приёма по 50 г;
- **template:** шаблон TimSim на 7 приёмов (5.2 в сутки).

Оба: `isf_cv = 0.15`, behaviour (rescue), compression 3.5/30 дней, autoISF off, чистый пин
`74271a544b`. Критерии gate — те же, что в A25 (не подкручивались); fingerprint дизайна
`23c6f8e102a855db`.

## 3. Вывод

1. **Ни одно плечо не проходит gate.** Медианы проходят, индивидуальные хвосты — нет. Это
   подтверждает A25 на 22× большем exposure: проблема не в коротком окне.
2. **Шаблонная еда примерно вдвое снижает tail burden:** severe 7 → 4, worst <54 401 → 272
   мин/сут, P90 147 → 30.5, TBR P90 0.168 → 0.081, медиана TIR 0.712 → 0.797. Направление
   совпадает с A31/A34.
3. **Но хвост остаётся:** у худшего субъекта даже template-плеча 272 мин/сут ниже 54 и
   непрерывный низ 175 мин. Это не клинический вывод, но и не «шум».
4. **P90 — важнее среднего:** медиана `<54` равна нулю в обоих плечах, а P90 различается в
   5 раз. Отчёт только по средним скрыл бы эффект.
5. **660 subject-days всё ещё мало для редких событий:** верхняя граница ~1.7/subject-year при
   нуле событий. Для утверждений о безопасности нужны тысячи subject-days и больше субъектов.

## 4. Ограничения

1. Плечи не off/autoISF/DynISF (как в A25), а fixed/template при autoISF off и drift 15 %;
   сравнивать с A25 можно по масштабу tail, не по ранжированию алгоритмов.
2. Один seed; 30 базовых субъектов; без site failure и M3.
3. Gate-критерии — консенсусные пороги плюс собственные tail-пороги стенда.
4. Severe event определён как непрерывный низ ≥ 120 мин; это выбор стенда.
5. Числа с чистого пина `74271a544b`.
