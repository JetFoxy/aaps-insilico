# W3 — model-движок, подбор субъекта и сравнение с реальным днём

Дата: 2026-11-23
Статус: **не принят** — движок работает и детерминирован, но с новым seed history сравнение
с реальным днём не выдерживает: одноточечный `glucose_offset` равен **−149.0 мг/дл**, модельная
линия после сдвига уходит ниже физиологического минимума, и модельные TIR/TBR/LBGI нельзя
интерпретировать. Это модель, а не клинический прогноз.

## 1. Постановка

По спеке §5, режим `model` отвечает на вопрос «что было бы с глюкозой»: реальные еда и болюсы
пользователя проигрываются на виртуальном субъекте когорты, алгоритм получает **профиль
пользователя** из Nightscout (ISF, CR, цель, базал), а субъект даёт только физиологию.
Задача W3 — собрать движок, подобрать субъекта по лог-расстоянию TDI/CR/ISF, прогнать окно
с seed-историей и сравнить модельные TIR/TBR/LBGI с реальным трейсом.

Прогон: реальный трейс из W1 с 8-часовым lookback, окно 72 ч, тёплый старт 8 ч, шум сенсора
выключен, `seed=0`, baseline-алгоритм autoISF с SMB. Параметры модели и подбора не менялись.

## 2. Подбор субъекта

Из профиля пользователя: TDI 68.2 ед/сут (сумма базала за сутки и ручных болюсов, приведённых
к суткам), CR 7.1 г/ед, ISF 50.4 мг/дл/ед. CR и ISF берутся из профиля на `window_start`,
TDI считается по трейсу.

| | TDI, ед/сут | CR, г/ед | ISF, мг/дл/ед |
|---|---|---|---|
| Пользователь | 68.2 | 7.1 | 50.4 |
| Субъект `adult#010` | 49.6 | 7.14 | 34.2 |

- Субъект: **`adult#010`**.
- Расстояние в лог-пространстве: **0.500** (порог `good` — 0.35, зафиксирован до первого
  прогона и не менялся).
- Confidence: **low**. По спеке §5.1 это означает плашку «похожесть низкая, результат —
  иллюстрация».
- Различие даёт в основном TDI (68.2 против 49.6) и ISF (50.4 против 34.2); CR совпал почти
  точно. Физиология субъекта — не физиология пользователя.

## 3. Прогон

| Параметр | Значение |
|---|---|
| Окно | 72 ч |
| Тёплый старт | 8 ч (480 мин) |
| Lookback до окна | 160 точек CGM и 138 лечений (в т.ч. 8 приёмов пищи / 270 г и 38 болюсов / 24.63 ед) |
| Длительность сценария | 4800 мин, 960 циклов по 5 мин |
| Отчётные циклы | 864 (всё, что после 8 ч) |
| Еда | 62 записи, 1770 г суммарно (в отчётном окне 54 записи / 1500 г), режим `announced` |
| Болюсы | 326 записей, 179.16 ед суммарно (в отчётном окне 288 записей / 154.53 ед) |
| Исключено loop-болюсов | 282 (33 из них — в lookback) |
| Неклассифицированные болюсы | 353 — включены как ручные (правило Task 6) |
| Пропуски CGM | 1 пропуск > 15 мин |
| `glucose_offset` | **−149.0 мг/дл** |
| Модельный инсулин | SMB 164.85 ед, базал 5.08 ед, ручные 154.53 ед, всего 324.45 ед |
| Темп базала модели | средний 0.07 ед/ч, минимум 0, максимум 2.78 ед/ч |
| Время прогона | 96 с (97 с user вместе со стартом JVM-моста) |

`glucose_offset` — сдвиг, при котором модельная глюкоза в конце тёплого старта совпадает с
реальной в `window_start`. В конце тёплого старта модель оказалась на 149 мг/дл **выше**
реальной, поэтому сдвиг отрицательный и складывается со всей линией. Это не сброс состояния:
компартменты инсулина и углеводов остаются модельными.

## 4. Модель против реального трейса

Реальные метрики посчитаны по точкам CGM окна (3138 точек), модельные — по 864 отчётным
циклам после сдвига на `glucose_offset`.

| Метрика | Модель | Реальный трейс |
|---|---|---|
| Точек / циклов | 864 | 3138 |
| Средняя глюкоза, мг/дл | 15.6 | 120.7 |
| TIR 70–180 | 16.2% | 94.5% |
| TBR < 70 | 70.4% | 3.1% |
| TBR < 54 | 67.7% | 0.3% |
| LBGI | 14.02 | 1.00 |

Эти модельные числа — артефакт выравнивания, а не гипогликемия. До сдвига средняя модельная
глюкоза 164.6 мг/дл; сдвиг −149.0 опускает всю линию, в том числе ниже нуля. При расчёте LBGI
часть сдвинутых значений не положительна, поэтому в логарифме было предупреждение
`divide by zero`; LBGI 14.02 не интерпретируется. Сравнение TIR/TBR по такой линии не имеет
клинического смысла.

Вероятная причина расхождения в тёплом старте: 33 pre-window loop-болюса (SMB) исключены из
сценария по тому же правилу, что и в окне, поэтому 8-часовая история инсулина виртуального
пациента неполная; плюс ISF субъекта (34.2) ниже пользовательского (50.4) при 270 г углеводов
в lookback. Поциклового разбора в W3 нет — это гипотеза по агрегатам.

## 5. Ограничения

1. **Это модель, а не прогноз.** Числа не описывают, что случится с пользователем; они
   показывают поведение выбранной физиологии под его едой, болюсами и настройками.
2. **Низкая похожесть субъекта.** Distance 0.500 при пороге 0.35; TDI и ISF отличаются
   в 1.4–1.5 раза. Модельный ряд нельзя читать как «ожидаемую глюкозу».
3. **Одноточечное выравнивание не работает при большом расхождении.** `glucose_offset`
   компенсирует разницу только в конце тёплого старта; при расхождении 149 мг/дл сдвиг
   переносит всю ошибку на отчётное окно. В этом прогоне абсолютные TIR/TBR/LBGI непригодны.
4. **Неполная seed history.** Pre-window loop-болюсы исключены из сценария, поэтому IOB и
   глюкоза на старте окна не полностью соответствуют реальной истории лечения.
5. **Один профиль на всё окно.** ISF/CR/цель/базал берутся из профиля на `window_start`;
   внутрисуточные переключения профиля не воспроизводятся.
6. **TDI из трейса.** TDI считается как базал за сутки плюс ручные болюсы, приведённые к
   суткам, а не берётся из записи настроек.
7. **Еда объявлена.** Углеводы из Nightscout подаются как объявленные, без ошибки времени и
   количества; скорость опорожнения желудка — модельная.
8. **Не воспроизводятся** temp target, autosens-отклонения, exercise, реальные temp basal и
   смена профиля; loop-SMB исключены, неклассифицированные болюсы считаются ручными.
9. **Разная дискретизация.** Реальный CGM — 3138 точек, модель — 5-минутные циклы; TIR/TBR
   сравниваются как доли времени, а не по парам точек.
10. **Шум выключен, детерминизм по seed сохранён.** Результат не включает вариабельность
    сенсора; параметры подбора и модели в этом прогоне не менялись.
11. **Не клиническая валидация.** Ядро — производная S2008/S2013, не официальная
    UVA/Padova; отчёт не заменяет клиническую проверку.

## 6. Вердикт

W3 **не принят**. Движок режима `model` работает: подбор субъекта, реальные еда и болюсы,
seed history и детерминированный прогон выполняются без падений, время прогона 96 с. Но
сравнение с реальным днём при новом lookback не выдерживает: `glucose_offset` −149.0 мг/дл,
сдвинутая модельная линия уходит ниже нуля, модельные TIR 16.2% / TBR < 70 70.4% / LBGI 14.02
против реальных 94.5% / 3.1% / 1.00 не являются клиническими величинами. Параметры не
подкручивались, результат зафиксирован как есть.

Чтобы W3 мог быть принят, нужен отдельный дизайн-фикс, например учитывать pre-window
loop-болюсы в seed history или отказываться от прогона при слишком большом расхождении на
выравнивании. В этой задаче такие изменения не вносились. Результат остаётся иллюстрацией,
а не прогнозом; в UI (Task 10) обязательна плашка «это модель, а не ваш день».
