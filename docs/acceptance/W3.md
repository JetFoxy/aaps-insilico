# W3 — model-движок, подбор субъекта и сравнение с реальным днём

Дата: 2026-11-23
Статус: **принят** — движок и методика W3 приняты: seed history теперь включает pre-window
SMB, `glucose_offset` выводится как диагностика, а TIR/TBR/LBGI считаются по несдвинутой
модельной глюкозе. Клиническая интерпретация чисел не принята: похожесть субъекта низкая,
модельные TIR/TBR далеки от реального дня. Это модель, а не клинический прогноз.

## 1. Постановка

По спеке §5, режим `model` отвечает на вопрос «что было бы с глюкозой»: реальные еда и болюсы
пользователя проигрываются на виртуальном субъекте когорты, алгоритм получает **профиль
пользователя** из Nightscout (ISF, CR, цель, базал), а субъект даёт только физиологию.
Задача W3 — собрать движок, подобрать субъекта по лог-расстоянию TDI/CR/ISF, прогнать окно
с seed-историей и сравнить модельные TIR/TBR/LBGI с реальным трейсом.

Методика после исправлений:

- в тёплом старте учитываются **все** реальные болюсы, включая loop SMB: это инсулин, который
  сформировал состояние на `window_start`;
- в отчётном окне реальные loop SMB не учитываются, потому что SMB в окне доставляет уже
  алгоритм модели, иначе они удвоились бы;
- `glucose_offset = model_glucose_at(warmup) − real_glucose_at(window_start)` — только
  диагностика расхождения на выравнивании; модельная линия не сдвигается, TIR/TBR/LBGI
  считаются по несдвинутой глюкозе.

Прогон: реальный трейс из W1 с 8-часовым lookback, окно 72 ч, тёплый старт 8 ч, шум сенсора
выключен, `seed=0`, baseline-алгоритм autoISF с SMB. Параметры модели и подбора не менялись.

## 2. Подбор субъекта

Из профиля пользователя: TDI 68.2 ед/сут (сумма базала за сутки и ручных болюсов, приведённых
к суткам), CR 7.1 г/ед, ISF 50.4 мг/дл/ед. CR и ISF берутся из профиля на `window_start`,
TDI считается по трейсу.

| | TDI, ед/сут | CR, г/ед | ISF, мг/дл/ед |
|---|---|---|---|
| Пользователь | 68.2 | 7.1 | 50.4 |
| Субъект `adult#010` | 49.6 | 7.14 | 34.2 |

- Субъект: **`adult#010`**.
- Расстояние в лог-пространстве: **0.500** (порог `good` — 0.35, зафиксирован до первого
  прогона и не менялся).
- Confidence: **low**. По спеке §5.1 это означает плашку «похожесть низкая, результат —
  иллюстрация».
- Различие даёт в основном TDI (68.2 против 49.6) и ISF (50.4 против 34.2); CR совпал почти
  точно. Физиология субъекта — не физиология пользователя.

## 3. Прогон

| Параметр | Значение |
|---|---|
| Окно | 72 ч |
| Тёплый старт | 8 ч (480 мин) |
| Lookback до окна | 160 точек CGM и 138 лечений; в тёплом старте 8 приёмов пищи / 270 г и 71 болюс / 35.55 ед, включая 33 loop SMB / 10.93 ед |
| Длительность сценария | 4800 мин, 960 циклов по 5 мин |
| Отчётные циклы | 864 (всё, что после 8 ч) |
| Еда | 62 записи, 1770 г суммарно (в отчётном окне 54 записи / 1500 г), режим `announced` |
| Болюсы | 359 записей, 190.08 ед суммарно (в отчётном окне 288 записей / 154.53 ед) |
| Исключено loop-болюсов в окне | 249 |
| Неклассифицированные болюсы | 353 — включены как ручные (правило Task 6) |
| Пропуски CGM | 1 пропуск > 15 мин |
| `glucose_offset` | **+143.0 мг/дл** (модель − реальность на выравнивании) |
| Модельный инсулин | SMB 163.25 ед, базал 5.20 ед, ручные 154.53 ед, всего 322.98 ед |
| Темп базала модели | средний 0.07 ед/ч, минимум 0, максимум 2.78 ед/ч |
| Время прогона | 89 с (93 с user вместе со стартом JVM-моста) |

`glucose_offset` — диагностика, а не поправка. В конце тёплого старта модель оказалась на
143 мг/дл выше реальной; это расхождение выводится отдельной строкой, но модельная линия не
сдвигается. Включение 33 pre-window loop SMB изменило разрыв с +149 до +143 мг/дл (по той же
формуле «модель − реальность»), то есть почти не закрыло его: основной вклад даёт физиология
субъекта, а не пропущенная часть SMB-истории.

## 4. Модель против реального трейса

Реальные метрики посчитаны по точкам CGM окна (3138 точек), модельные — по 864 отчётным
циклам на **несдвинутой** модельной глюкозе.

| Метрика | Модель | Реальный трейс |
|---|---|---|
| Точек / циклов | 864 | 3138 |
| Средняя глюкоза, мг/дл | 164.1 | 120.7 |
| TIR 70–180 | 34.4% | 94.5% |
| TBR < 70 | 28.0% | 3.1% |
| TBR < 54 | 21.5% | 0.3% |
| LBGI | 8.64 | 1.00 |

Модель держит среднюю глюкозу выше реальной, но даёт заметные и глубокие гипогликемии: TBR
28.0% против 3.1%, TBR < 54 21.5% против 0.3%. По агрегатам вероятная причина — низкая
похожесть: ISF субъекта 34.2 мг/дл/ед против пользовательских 50.4, поэтому те же дозы и цель
из профиля пользователя роняют глюкозу сильнее; TDI субъекта при этом ниже. Поциклового
разбора в W3 нет — это гипотеза по агрегатам.

## 5. Ограничения

1. **Это модель, а не прогноз.** Числа не описывают, что случится с пользователем; они
   показывают поведение выбранной физиологии под его едой, болюсами и настройками.
2. **Низкая похожесть субъекта.** Distance 0.500 при пороге 0.35; TDI и ISF отличаются
   в 1.4–1.5 раза. Модельный ряд нельзя читать как «ожидаемую глюкозу».
3. **Offset — диагностика.** Модель на выравнивании выше реальности на 143 мг/дл; линия не
   сдвигается, поэтому абсолютные TIR/TBR/LBGI содержат эту известную systematic-ошибку.
   Offset показывает её величину, но не устраняет.
4. **Seed history неполная по построению.** Pre-window loop SMB теперь включены, но реальные
   pre-window temp basal и прочие события не моделируются; в окне loop SMB исключены, чтобы
   не удвоить SMB алгоритма модели.
5. **Один профиль на всё окно.** ISF/CR/цель/базал берутся из профиля на `window_start`;
   внутрисуточные переключения профиля не воспроизводятся.
6. **TDI из трейса.** TDI считается как базал за сутки плюс ручные болюсы, приведённые к
   суткам, а не берётся из записи настроек.
7. **Еда объявлена.** Углеводы из Nightscout подаются как объявленные, без ошибки времени и
   количества; скорость опорожнения желудка — модельная.
8. **Не воспроизводятся** temp target, autosens-отклонения, exercise, реальные temp basal и
   смена профиля; неклассифицированные болюсы считаются ручными.
9. **Разная дискретизация.** Реальный CGM — 3138 точек, модель — 5-минутные циклы; TIR/TBR
   сравниваются как доли времени, а не по парам точек.
10. **Шум выключен, детерминизм по seed сохранён.** Результат не включает вариабельность
    сенсора; параметры подбора и модели в этом прогоне не менялись.
11. **Не клиническая валидация.** Ядро — производная S2008/S2013, не официальная
    UVA/Padova; отчёт не заменяет клиническую проверку.

## 6. Вердикт

W3 **принят** как движок и методика режима `model`: подбор субъекта, seed history со всеми
pre-window болюсами, реальные еда и болюсы, профиль пользователя, диагностический offset и
детерминированный прогон работают без падений. Исправлены обе проблемы предыдущего прогона:
SMB из lookback больше не теряются, а одноточечный сдвиг не искажает TIR/TBR/LBGI.

Клиническая интерпретация не принята: похожесть низкая (0.500), модельные TIR 34.4% /
TBR < 70 28.0% / TBR < 54 21.5% / LBGI 8.64 против реальных 94.5% / 3.1% / 0.3% / 1.00.
Это иллюстрация поведения субъекта `adult#010` под настройками пользователя, а не прогноз.
В UI (Task 10) обязательна плашка «это модель, а не ваш день».
