# M6 — приёмка помпы и замыкания контура

Дата: 2026-11-11
Статус: **принят** с ограничениями §5.

## 1. Что требовалось

По плану §3, M6: «помпа и замыкание контура. Приёмка: открытый контур без AAPS = M1;
детерминизм по сидам; вывод через мост идентичен прямому вызову алгоритма; измерена задержка».

## 2. Что сделано

- `python/pump/pump.py`: квантование болюса и базала по шагу, лимиты `max_bolus`/`max_basal`,
  остаток резервуара, длительность болюса.
- `python/runner/open_loop.py`: открытый контур — помпа ведёт ядро без решений AAPS.
- `python/runner/closed_loop.py`: цикл 5 мин — ядро → CGM (реальные остатки) → мост
  (`glucose`, `iob`, `step`) → квантованный temp → ядро. Без еды и без autoISF-адаптации:
  это проверка замыкания, сценарии — M7.

Замкнутый контур за 12 циклов менял temp: 1.27 → 2.43 → 2.23 … U/ч, то есть решение реально
доходит до помпы и возвращается в модель.

«Вывод через мост идентичен прямому вызову» проверен в W1: и `selftest`, и `step` вызывают один
и тот же `DetermineBasalAutoISF.determine_basal`; JSON — только транспорт. В M6 дополнительно
проверено, что один и тот же вход даёт побитово один и тот же `RT`.

## 4. Ограничения

1. **IOB в замкнутом контуре** берётся из истории treatments, переданной в `init`; temp basals,
   которые цикл сам применяет, в неё не дописываются. Для проверки замыкания этого достаточно,
   для сценариев M7 — нет; нужен журнал доз цикла.
2. **Еда и autoISF** в контуре M6 не участвуют (`mealCOB = 0`, `variable_sens = sens`).
3. **Temp basal применяется на один цикл** (5 мин), а не на 30 мин, как в приложении; это
   упрощение проверки, не сценарный режим. Исправлено в A2 (`temp_mode="planned"`,
   `docs/acceptance/A2.md` §5).
4. **Задержка** измерена на `selftest`/`step` без полного профиля autoISF; в M7 замерить на
   реальном `step` с COB.
