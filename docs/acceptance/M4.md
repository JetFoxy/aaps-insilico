# M4 — приёмка CGM

Дата: 2026-11-10
Статус: **принят**. Шум — реальные остатки xDrip, не синтетическая модель.

## 1. Что требовалось

По плану §3, M4: «CGM: лаг, калибровка, шум из реальных остатков, каденс, округление.
Приёмка: спектр синтетического шума совпадает с реальными остатками (наклон PSD); каденс и
округление работают; реальный плагин сглаживания вызывается из стенда».

## 2. Что сделано

`python/cgm/`:
- `residuals.py` — остатки `BgReadings.raw_data` против локального Savitzky-Golay (7, 2) внутри
  непрерывного сегмента; сегменты не склеиваются, разрыв > 20 мин режет сегмент.
- `noise.py` — `BlockNoise` (реплей непрерывного окна реальных остатков) и `AR1Noise` только как
  документированный fallback.
- `sensor.py` — цепочка: лаг первого порядка (`tau_lag_min`), линейная калибровка
  (`scale`, `offset`), аддитивный шум, выборка с каденсом 1–5 мин, квантование, насыщение 39–400.

Источник данных: xDrip `BgReadings`, октябрь 2026 (Oct 8 – Nov 1), `raw_data` — то, что реально
получает AAPS (`EXTRA_RAW`).

## 3. Параметры реальных остатков

| Величина | Значение |
|---|---|
| Остатков | 11 422 |
| σ | 2.49 мг/дл |
| lag-1 автокорреляция | −0.31 |
| Наклон PSD (Welch, 0.002–0.08 цикл/мин) | 3.72 |
| Квантование в базе | 1 мг/дл (целые) |

Отрицательная lag-1 и положительный наклон — следствие detrending SG(7,2): фильтр снимает
низкочастотную составляющую, остаток доминируется высокочастотной (квантование). Это то же
определение остатка, что `residRMS` в #5227, поэтому спектр сравнивается с ним же.

**Важно для сценариев:** длина блока — параметр. Короткие блоки «уплощают» спектр
(30 отсчётов → наклон 1.7 против 4.7 реального). По умолчанию `BlockNoise` берёт окно длиной
в весь прогон; так спектр сохраняется.

## 4. Результаты

| Тест | Порог | Факт |
|---|---|---|
| Наклон PSD: реальные vs синтетические | \|Δ\| < 0.6 | **3.72 vs 3.59** |
| σ синтетики vs реальных | < 25 % | 2.49 vs ~2.4 |
| Детерминизм по сиду | побитово | ✅ |
| Лаг: 50 % фронта при `tau=10` | 106.9 ± 2 мин | ✅ |
| Каденс 5 мин | 121 точка, шаг 5 | ✅ |
| Округление/насыщение | целые, 39–400 | ✅ |

Реальный плагин сглаживания — тот же `UnscentedKalmanFilterPlugin`, который вызывает мост W1
(команда `glucose`): отдельного кода для M4 не потребовалось.

## 5. Ограничения

1. **Шум нестационарен**: σ и спектр зависят от сегмента сенсора и периода. Один набор остатков
   не описывает все сессии; в сценариях нужно перечислять, какой набор использован.
2. **Нет reference BG**, поэтому нельзя говорить о «правильном» шуме — только о совпадении
   спектра с реальными остатками.
3. **Калибровка** в октябре не применялась (нет событий `Calibration`), по умолчанию `1.0/0.0`.
4. **Квантование** 1 мг/дл, потому что AAPS округляет `BgEstimate` до целого. Утверждение
   «1.8 мг/дл» из проектной записки относится к 0.1 ммоль/л и к mg/dL-потоку не применяется.
5. Остатки считаются по `raw_data`; `calculated_value` (display xDrip) даёт другой спектр —
   это отдельный сценарий, не текущий.
