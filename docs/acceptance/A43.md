# A43 — lispro PK variant: проверка пред-регистрации

Дата: 2026-11-27
Статус: **принят как отрицательный/смешанный результат**. Вариант впервые проходит gate, но
меняет тип отказа: убирает затяжной низ, ухудшает восстановление и `diurnal`. По умолчанию
не включается.

## 1. Постановка

A42 пред-регистрировал opt-in `--insulin-pk lispro`: подкожные параметры быстрого аналога из
открытой популяции (Schiavon 2018; Faggionato 2021), задержка болюсов `τ`, без изменения модели
действия. Прогон: 27 валидных субъектов × 22 суток, template-еда, behaviour, compression 3.5,
drift 15 %, M3 off, чистый пин `74271a544b`.

## 2. Ожидания A42 → факт

| Ожидание | Факт |
|---|---|
| пик абсорбции раньше | медиана 1 ЕД-надира 231 → 219 мин, но **10/27 субъектов позже** (adult#009 342→400, adult#010 264→369) |
| надир 1 ЕД короче | не подтверждено как общий эффект; хвост в основном от модели действия, не от sc |
| longest-low не хуже | **выполнено:** 150 → 115 мин; тяжёлых 2 → 0 |
| `diurnal` не хуже | **не выполнено:** 67.5 → 70.0 (p=0.006) |
| TIR не ниже | **не выполнено:** 0.798 → 0.775 |

Медианное падение на 1 ЕД почти не изменилось (25.7 → 26.8 мг/дл): меняется тайминг, не
величина.

## 4. Вывод

1. **Гипотеза «хвост от подкожной абсорбции» подтверждена лишь частично.** Замена sc-кинетики
   убирает затяжной низ (150 → 115, тяжёлых 0), но не сокращает надир у большинства субъектов:
   длинный хвост в основном от модели действия инсулина (`m1–m4`, `p2u`, `ki`), а не от `ka/kd`.
2. **Первый проход gate — не доказательство безопасности.** 594 subject-days, один seed;
   при нуле тяжёлых событий rule-of-three даёт верхнюю границу ~1.7 на subject-year. Худший
   субъект всё равно проводит 39 мин/сут ниже 54, TBR 0.081 — у самой границы 0.10.
3. **Вариант меняет тип отказа:** меньше затяжных низов, но быстрее восстановление (hypo_rec 45,
   ниже конверта), чуть выше `diurnal` и ниже TIR. Scorecard падает 7 → 6.
4. **По умолчанию не включается.** S2008-базлайн остаётся; lispro — sensitivity analysis,
   показывающий, что оставшиеся пробелы нельзя списать на одну подкожную кинетику.
5. **Следующий шаг, если продолжать:** source review модели действия (`p2u`, `ki`, `m1–m4`) —
   без него дальнейшие PK-варианты будут лишь перекладывать отказ.

## 5. Дополнение A44

Кривая действия модели (пик 83 мин, хвост ~304 мин) внутри опубликованного диапазона быстрых
аналогов; менять `p2u/ki/m1–m4` не по чему. Оставшийся хвост — взаимодействие контроллера и еды.

## 6. Ограничения

1. Источник — lispro, не Lyumjev; популяция 116 взрослых, перенос на детей — допущение.
2. BMI-ковариата `ka2` не применена (нет роста/ИМТ) — используется reference BMI.
3. `τ` реализована сдвигом болюсов; базал не задерживается (постоянный вход).
4. 27 субъектов, один seed, 22 суток; gate — скрин.
5. Числа с чистого пина `74271a544b`.
