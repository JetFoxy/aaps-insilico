# A44 — кривая действия инсулина: модель против публикаций

Дата: 2026-11-27
Статус: **negative / blocked**. Кривая действия модели находится внутри опубликованного
диапазона для быстрых аналогов; источник на изменение `p2u/ki/m1–m4` отсутствует. Линия
тюнинга модели закрывается: оставшиеся пробелы — взаимодействие контроллера и еды.

## 1. Вопрос

A43 показал: замена подкожной кинетики убирает затяжной низ, но не сокращает надир у
большинства. Остаётся ли хвост из-за слишком длинного **действия** инсулина в модели, и можно
ли его исправить по источнику?

## 2. Метод

Для 27 валидных субъектов: базал + 1 ЕД болюс, 600 мин; из трассы берётся состояние действия
`X(t) = x[6]` (remote insulin action, уравнение A10), вычитается `X(0)`. Для каждой кривой:
время пика, длительность выше 50 % и 10 % пика. Сравнение S2008-кинетики и lispro-варианта.

## 3. Результат

| Метрика | S2008 | lispro | Опубликовано (быстрые аналоги) |
|---|---|---|---|
| Пик действия, мин | **83** | **83** | 60–120 (CDC: ~60; Merck: 1–2 ч) |
| Длительность >50 %, мин | 154 | 148 | — |
| Длительность >10 %, мин | **304** | 302 | ~4–5 ч (240–300) |
| Onset (по литературе) | — | — | 15–27 мин (StatPearls) |

Источники: StatPearls «Insulin Lispro» (onset 23–27 мин, длительность ~5 ч; lispro-aabc —
15–18 мин и ~4 ч); CDC «Types of Insulin» (пик ~1 ч, 2–4 ч); Merck Manual table (1–2 ч, 3–5 ч).

Кривая действия модели: пик 1.4 ч, хвост ~5 ч по порогу 10 % — **внутри** опубликованного
диапазона. Подкожная замена (lispro) почти не меняет эти метрики (83→83, 304→302).

## 4. Вывод

1. **Действие инсулина в модели не является аномально длинным.** 83 мин до пика и ~5 ч хвоста
   соответствуют быстрым аналогам. Поэтому длинный **глюкозный** надир (231–365 мин в A3) — не
   следствие растянутой кривой действия, а комбинация дозы, приёма пищи и замкнутого контура.
2. **Источника на изменение `p2u/ki/m1–m4` нет.** В реестре они `todo`; опубликованные
   популяционные значения S2017 не раскрыты. Менять их «чтобы надир стал короче» — фит.
3. **A43 согласуется:** замена sc-кинетики меняет тайминг, но не величину и не кривую действия;
   тип отказа перекладывается, а не устраняется.
4. **Линия тюнинга модели закрыта.** Оставшиеся `diurnal` 67.5, `hypo_reb` 50 и longest-low —
   взаимодействие контроллера (SMB после еды) с моделью, а не отсутствующий параметр PK/PD.
   Дальнейшее улучшение требует либо нового контроллера/сценария, либо новых опубликованных
   данных, а не правки коэффициентов.

## 5. Ограничения

1. `X(t)` — модельное состояние действия, не euglycaemic clamp; пороги 10/50 % — выбор стенда.
2. Опубликованные диапазоны широкие и относятся к разным препаратам (lispro, lispro-aabc,
   aspart); сравнение ориентировочное.
3. 27 субъектов, один seed; S2008 и lispro — не S2017-вектор.
4. Числа с чистого пина `74271a544b`.

## 6. Воспроизведение

```bash
.venv/bin/python - <<'PY'
import numpy as np
from simcore.params import load_subjects
from simcore.model import simulate, Schedule, Bolus
from simcore.insulin_pk import apply_lispro
from runner.profiles import eligible_names
subs = load_subjects()
for name in eligible_names(subs):
    for subject in (subs[name], apply_lispro(subs[name], seed=0)):
        tr = simulate(subject, Schedule(subject.basal_u_per_min, boluses=[Bolus(0, 1.0)]), 600, 1.0)
        x = tr.x[6] - tr.x[6][0]
        print(name, int(np.argmax(x)), int((x >= 0.1 * x.max()).sum()))
PY
```
