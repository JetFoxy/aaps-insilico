# A9 — кросс-проверка с LT1 (UVA/Padova T1DMS)

Дата: 2026-11-11
Статус: **принят как сравнение моделей**, не как валидация.

## 1. Зачем

LT1 (LoopInsighT1, Ульм) содержит UVA/Padova T1DMS — модель, воспроизводящую коммерческий
симулятор. Это независимый ориентир: насколько наше ядро S2017 ведёт себя как «эталонная»
UVA/Padova на одном и том же сценарии.

## 2. Постановка

- LT1: пациент по умолчанию `UvaPadova_T1DMS`, контроллер CSII (только базал), идеальный CGM,
  один необъявленный приём 50 г за 15 мин на 2-м часу, 8 ч.
- Наше ядро: `adult#001`, `adolescent#003`, `child#005`, тот же базал и тот же приём, 8 ч.
- Скрипт LT1: `tools/lt1/compare.ts` (кладётся в `loopinsight1/examples/Compare/`).

## 3. Результаты (Δ относительно глюкозы перед едой)

| Модель / субъект | Базалайн | Δпик | Время пика после еды | +2 ч | +4 ч | +6 ч |
|---|---|---|---|---|---|---|
| LT1 UVA/Padova (по умолчанию) | 99.9 | **+127.2** | **203 мин** | +99.9 | +121.2 | +89.7 |
| наш `adult#001` | 138.6 | +99.3 | 120 мин | +99.3 | +66.1 | +38.5 |
| наш `adolescent#003` | 145.9 | +146.7 | 132 мин | +145.6 | +112.0 | +73.4 |
| наш `child#005` | 137.9 | +235.9 | 242 мин | +152.9 | +235.8 | +198.5 |

## 4. Что видно

1. **Порядок величины совпадает:** 50 г без болюса дают пик +100…+240 мг/дл в обеих моделях.
2. **Наш взрослый «быстрее»:** пик на 120-й минуте против 203 у LT1, и к 6-му часу остаётся +38
   против +90. То есть наша модель очищает приём раньше, LT1 держит хвост дольше.
3. **Разброс когорты больше, чем разница моделей:** `child#005` даёт +236 и пик на 242-й минуте —
   ближе к временной шкале LT1, но с гораздо большей амплитудой.
4. Это не ошибка: у LT1 другой пациент (базалайн 100 против 139), другая реализация всасывания и
   действия инсулина, и мы уже знаем (A3), что действие инсулина в derived-когорте в 2.4 раза
   слабее клинического правила. Сравнение фиксирует расхождение, а не «кто прав».

## 5. Ограничения

1. Пациент LT1 по умолчанию не идентифицирован как конкретный взрослый из T1DMS; сравнение
   качественное.
2. Без болюса: проверяется только приём + базал, не CF.
3. Наш приём задан 15-минутным окном, как у LT1, но модель всасывания параметризована иначе.
4. Это не клинический вывод.

## 6. Воспроизведение

```bash
# LT1
git clone --depth 1 https://github.com/hpeuscher/loopinsight1.git /tmp/loopinsight1
cd /tmp/loopinsight1 && npm install
mkdir -p examples/Compare && cp <repo>/tools/lt1/compare.ts examples/Compare/
cd examples/Compare && node --loader ts-node/esm ./compare.ts

# наш
.venv/bin/python - <<'PY'
from simcore.params import load_subject
from simcore.model import Schedule, Meal, simulate
s = load_subject("adult#001")
tr = simulate(s, Schedule(s.basal_u_per_min, [Meal(120.0, 50.0, 50/15)]), 480.0, 1.0)
g = tr.glucose
print(g[120], g[120:].max(), 120 + int(g[120:].argmax()))
PY
```
